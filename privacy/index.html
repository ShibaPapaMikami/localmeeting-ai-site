プライバシーポリシー

ホームサポート

LocalMeeting AI（以下「本アプリ」）は、個人が開発・提供している macOS 向けの音声入力アプリです。本ポリシーは、本アプリが利用者の情報をどのように取り扱うかを説明します。

要点：開発者は、利用者の音声データ・認識結果・その他の個人情報を一切収集しません。通常のご利用では音声認識は端末内で完結し、音声も文字も端末の外へ送信されません。開発者が運営するサーバーは存在せず、アカウント登録も不要です。

唯一の例外として、利用者が設定画面で「接続先サーバー URL」を自ら指定した場合に限り、音声データはその指定先へ送信されます。この場合も送信先は利用者が選んだサーバーであり、開発者がそのデータを受け取ることはありません。詳しくは第4項をご覧ください。

1. 音声認識の仕組み

本アプリは、音声認識エンジンと認識モデルをアプリ本体に同梱しています。認識処理は、利用者の Mac の内部でのみ実行されます。

認識エンジン提供元ライセンス
ReazonSpeech k2-v2（標準）Reazon Human Interaction LabApache License 2.0
kodama-ja-streaming-small（軽量モード）ayousanzApache License 2.0

これらのモデルはアプリに同梱されており、利用にあたって外部からのダウンロードや外部サービスへの問い合わせは発生しません。認識に用いた音声は認識処理の直後に破棄され、ファイルとして保存されることはありません。

2. マイクの利用

本アプリは、音声を文字に変換するためにマイクを使用します。macOS の許可ダイアログで利用者が許可した場合にのみ、マイクへアクセスします。

  • 取得した音声は、端末内の音声認識処理にのみ使用します
  • 音声を録音ファイルとして保存する機能はありません
  • 音声を外部へ送信することはありません（第4項に記載する場合を除く）
  • メニューバーから音声入力を OFF にすると、マイクの取り込み自体を停止します

3. 認識結果の出力について

認識結果はクリップボードへコピーされます。ユーザーは Command+V で任意のアプリケーションへ貼り付けできます。本アプリは他のアプリケーションを操作する権限を要求しません。

  • 他のアプリの画面内容を読み取ることはありません
  • キーボード入力の監視・記録は行いません
  • クリップボードの内容は、次にコピーが行われるまで残ります。機密性の高い内容を扱う場合はご注意ください

4. 外部 ASR サーバー URL 機能について

本アプリの設定画面「詳細」には、「接続先サーバー URL」という上級者向けの項目があります。これは、利用者が自分で用意した音声認識サーバーへ接続するための機能です。

この欄が空欄の場合（初期状態）、本アプリは端末内（ws://127.0.0.1:8770）の同梱サーバーにのみ接続します。音声が端末の外へ出ることはありません。

利用者がこの欄に URL を入力した場合に限り、音声データはその接続先へ送信されます。この点について、以下をご理解ください。

  • 接続先は利用者自身が指定します。開発者が運営するサーバーではありません
  • 開発者は、送信先のサーバーや、そこで扱われるデータに一切関与せず、内容を知ることもできません
  • 送信されたデータの取り扱いは、その接続先の運営者の方針に従います。利用者の責任においてご利用ください
  • この機能は初期状態では無効であり、利用者が明示的に設定しない限り作動しません

5. 開発者が収集しない情報

開発者は、以下のいずれも収集しません。これらが開発者へ送信される仕組みは、本アプリに存在しません。

  • 音声データおよび音声認識の結果（文字）
  • 氏名、メールアドレス、アカウント情報
  • 端末の識別子、位置情報、連絡先、写真、ファイル
  • 利用状況の統計、解析情報、クラッシュレポート
  • 広告識別子およびトラッキングに関する情報

本アプリには、解析ツール、広告 SDK、トラッキング機能のいずれも組み込まれていません。開発者が運営するサーバーは存在せず、利用者の情報を受け取る手段もありません。

音声データが端末外へ送信される場合

音声データの送信について、正確には次のとおりです。

状態音声データの送信先
初期状態（通常のご利用）送信されません。端末内の同梱サーバーでのみ処理します
利用者が「接続先サーバー URL」を設定した場合利用者が指定したサーバーへ送信されます

後者の場合でも、送信先は利用者自身が指定したサーバーです。開発者はその通信に関与せず、送信されたデータを受け取ることも、内容を知ることもありません。

6. 第三者への提供

開発者は利用者の情報を収集しないため、開発者が第三者へ提供できる情報はありません。データの販売、共有、譲渡のいずれも行いません。

本アプリが利用しているオープンソースの音声認識モデルおよびライブラリの提供元は、本アプリの動作を通じて利用者の情報を受け取ることはありません。これらはすべて端末内で動作します。

ただし、第4項の外部 ASR サーバー URL 機能を利用者が設定した場合、その接続先は利用者が選んだ第三者となります。この送信は利用者の設定によるものであり、開発者が仲介するものではありません。

7. 法令に基づく開示

開発者は利用者の情報を保有していないため、開示の求めに応じられる情報はありません。利用者が「接続先サーバー URL」を設定して外部のサーバーへ送信したデータについては、そのサーバーの運営者が取り扱いの主体となります。

8. 子どもの利用について

本アプリは特定の年齢層を対象としたものではなく、開発者はいかなる利用者からも個人情報を収集しません。

9. 本ポリシーの変更

本ポリシーを変更する場合は、このページを更新し、上部の最終更新日を改めます。重要な変更がある場合は、アプリの更新情報でもお知らせします。
